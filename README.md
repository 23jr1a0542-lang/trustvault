# TrustVault – Secure Document Management System

TrustVault is a web-based document management application built using Java and Spring Boot. It provides user authentication and a centralized platform for managing documents securely.

## Features
- User authentication and login
- Secure document management
- Spring Security integration
- Database integration using MySQL
- Persistent storage using Spring Data JPA and Hibernate

## Technologies Used
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- HTML, CSS, and JavaScript (if used in the project)

## Database Configuration
Configure your MySQL database and set the following environment variables before running the application:

- `DB_USERNAME`
- `DB_PASSWORD`

Do not publish real database passwords or other secrets.

## Running the Project
1. Clone this repository.
2. Create the `trustvault_db` database in MySQL.
3. Configure the database environment variables.
4. Run the Spring Boot application from Eclipse or using Maven.
